AEVEMORA V8.5 · 测试页精修版

本次专门重做“36 道测试题”的答题界面。

你截图中的问题：
- 问题文字顶在左侧，缺少版式层级
- 四个选项横向铺得太满，视觉像普通表单
- 整个页面只有问题+按钮，显得单调
- 底部 Footer 在答题过程中露出，进一步削弱沉浸感

V8.5 改进：
- 桌面端改成“左侧问题编号 / 时间原型图形 + 右侧题目与选项”的杂志式双栏
- 问题区整体向视觉中心移动，字体位置更自然
- 题目前增加 WHEN YOU HAVE TO DECIDE 小标题
- 大号问题编号 01–36 成为版式视觉元素
- 左侧加入与 AEVEMORA 品牌一致的几何时间环
- 四个选项缩窄并增加左侧编号、金色细线反馈
- 选项逐个轻微淡入，不再突然整页刷新
- 进度条重新设计为更细、更克制的顶部进度
- 答题时自动隐藏底部 Footer，结果页再恢复
- 手机端自动切换成单栏，不牺牲可点击面积

其他 V8.4 功能全部保留，包括人物肖像、结果页、海报、PWA、缓存与启动动画。
