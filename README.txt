AEVEMORA V9.4.1 · 过渡与首页修复版

本次只处理两个你截图里暴露出的实际问题：

1. 首页底部为什么提前出现一截答题页/历史图片
- 原因：答题区虽然有 CSS 隐藏，但多轮版本叠加后仅靠 display:none 不够稳。
- 现在 quiz 初始直接使用 HTML hidden 属性，并增加 #quiz[hidden]{display:none!important}。
- 页面加载时再次强制确认隐藏。
- 只有点击“开始测试”才解除 hidden。
- 回到首页、进入结果页时重新 hidden。
=> 首页不再出现答题页的一部分，也不会提前露出左侧图片。

2. 左侧文明图片切换为什么有卡顿
- 之前是切题时才开始访问并解码远程历史图片。
- 现在首页空闲阶段就预加载当前模式的 6 个文明场景。
- 下一章节还会提前解码。
- 图片只有在完成加载/解码后才替换。
- 左侧 Dossier 和右侧大背景统一使用淡出 → 换图 → 淡入。
- 网络图失败仍会回退到本地 SVG，不会空白。

文件数量仍低于 GitHub 网页端 100 文件限制。
